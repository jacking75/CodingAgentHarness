# 백업·복구 준비 검토 연습

실제 회사나 서비스 데이터가 아닌 가상 사례다. DB 접속 없이 정적 분석한다.

## 요청

```text
$mysql8-backup-recovery 이 문서의 입력만 사용해 검토 또는 설계해줘.
DB에 접속하거나 SQL을 실행하지 마. 부족한 정보와 확인 가능한 사실을 구분해줘.
```

## 입력

일요일에 full backup을 만들고 다음 일요일까지 보관한다. binlog는 24시간만 보관한다. 목요일 오후 사고 시 목요일 정오로 PITR하려 한다. 복원 훈련은 없고 “복제본이 있으니 RPO 0”이라고 주장한다.

## 실제 프로젝트 호출 예시

```text
$mysql8-backup-recovery 백업 정책과 최근 복원 훈련 기록을 검토해줘. RPO 10분, RTO 1시간 달성 여부를 증거 기준으로 판단해줘.
```

예시 경로는 실제 저장소 경로로 바꾼다. 다른 업무를 추가로 수행할 권한을 뜻하지 않는다.
