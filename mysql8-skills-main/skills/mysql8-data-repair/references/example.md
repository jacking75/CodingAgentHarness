# 데이터 보정·대사 계획 연습

실제 회사나 서비스 데이터가 아닌 가상 사례다. DB 접속 없이 정적 분석한다.

## 요청

```text
$mysql8-data-repair 이 문서의 입력만 사용해 검토 또는 설계해줘.
DB에 접속하거나 SQL을 실행하지 마. 부족한 정보와 확인 가능한 사실을 구분해줘.
```

## 입력

이벤트 E에서 일부 계정에 100재화가 두 번 지급됐다. 지급 원장에는 event_id, player_id, request_id, amount가 있다. 현재 잔액은 이미 소비로 변했다. 제안은 “이벤트 참가자 전원 balance=balance-100”이다. 정확한 대상 목록은 없다.

## 실제 프로젝트 호출 예시

```text
$mysql8-data-repair 이벤트 보상을 두 번 받은 계정을 대사하고 보정 계획을 작성해줘. UPDATE 실행은 하지 마.
```

예시 경로는 실제 저장소 경로로 바꾼다. 다른 업무를 추가로 수행할 권한을 뜻하지 않는다.
