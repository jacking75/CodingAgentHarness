# DB 권한·데이터 노출 리뷰 연습

실제 회사나 서비스 데이터가 아닌 가상 사례다. DB 접속 없이 정적 분석한다.

## 요청

```text
$mysql8-access-review 이 문서의 입력만 사용해 검토 또는 설계해줘.
DB에 접속하거나 SQL을 실행하지 마. 부족한 정보와 확인 가능한 사실을 구분해줘.
```

## 입력

```sql
GRANT ALL PRIVILEGES ON *.* TO 'ai_reader'@'%' WITH GRANT OPTION;
```

계정 목적은 특정 게임 DB의 메타데이터와 사전 정의한 집계만 조회하는 것이다. 연결 암호가 진단 로그에 출력된다.

## 실제 프로젝트 호출 예시

```text
$mysql8-access-review AI 진단 계정의 GRANT 초안을 검토해줘. 필요한 것은 특정 게임 DB의 메타데이터와 집계 지표 조회다.
```

예시 경로는 실제 저장소 경로로 바꾼다. 다른 업무를 추가로 수행할 권한을 뜻하지 않는다.
