# DB 정합성·회귀 테스트 설계 연습

실제 회사나 서비스 데이터가 아닌 가상 사례다. DB 접속 없이 정적 분석한다.

## 요청

```text
$mysql8-test-design 이 문서의 입력만 사용해 검토 또는 설계해줘.
DB에 접속하거나 SQL을 실행하지 마. 부족한 정보와 확인 가능한 사실을 구분해줘.
```

## 입력

claim(mail_id, player_id)는 한 번만 100재화를 지급해야 한다. 최초 지갑은 1000이다. 동일 요청 두 개, 서로 다른 요청 키로 같은 우편 수령, COMMIT 후 응답 유실이 가능하다. 코드와 테스트 DB는 제공하지 않는다.

## 실제 프로젝트 호출 예시

```text
$mysql8-test-design 우편 보상 수령의 중복 요청 테스트를 설계해줘. 먼저 DB에 연결하지 말고 두 연결의 실행 순서와 assertion을 문서화해줘.
```

예시 경로는 실제 저장소 경로로 바꾼다. 다른 업무를 추가로 수행할 권한을 뜻하지 않는다.
