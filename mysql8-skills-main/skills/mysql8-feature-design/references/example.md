# 신규 기능 DB 설계 연습

실제 회사나 서비스 데이터가 아닌 가상 사례다. DB 접속 없이 정적 분석한다.

## 요청

```text
$mysql8-feature-design 이 문서의 입력만 사용해 검토 또는 설계해줘.
DB에 접속하거나 SQL을 실행하지 마. 부족한 정보와 확인 가능한 사실을 구분해줘.
```

## 입력

계정별 우편함을 신규 설계한다. 우편 하나에 여러 보상이 있고 한 번만 수령한다. 수령 요청은 재시도될 수 있다. 만료 시간이 있으며 미수령 최신 우편 50개를 조회한다. 동일 DB 내 재화 지갑을 사용한다. 트래픽과 보존 기간은 아직 미정이다.

## 실제 프로젝트 호출 예시

```text
$mysql8-feature-design 보상 우편 기능을 설계해줘. 동일 우편은 한 번만 수령하고 계정별 최신 우편을 조회한다. docs/db/team-profile.md를 기준으로 설계 문서를 작성해줘.
```

예시 경로는 실제 저장소 경로로 바꾼다. 다른 업무를 추가로 수행할 권한을 뜻하지 않는다.
