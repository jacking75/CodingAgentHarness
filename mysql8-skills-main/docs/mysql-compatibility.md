# MySQL 8 버전·기능 확인표

“MySQL 8”만으로 운영 DDL·인증·실행 계획 기능의 동작을 확정하지 않는다. 8.0.x와 8.4.x의 실제 패치 버전·엔진·설정·배포판을 기록한다.

| 주제 | 검토 시 확인할 점 |
|---|---|
| CHECK | 8.0.16 이전과 이후의 강제 동작이 다르다. NULL과 NOT NULL도 별도 검토한다 |
| EXPLAIN ANALYZE | 8.0.18 이상 기능이며 실제 SQL을 실행한다. 대상 버전의 지원 구문을 확인한다 |
| INSTANT/INPLACE | 변경 종류·버전·테이블 조건에 따라 다르다. MDL과 공간 영향을 별도 검토한다 |
| DDL 트랜잭션 | 일반 DDL의 implicit commit과 atomic DDL을 구분한다 |
| UNIQUE와 NULL | nullable 키를 요청 중복 방지에 쓸 때 NULL 처리와 복합키 범위를 확인한다 |
| 파티셔닝 | 파티션 키와 모든 유일키의 관계, InnoDB FK 제한을 확인한다 |
| 잠금 | 격리 수준·인덱스·검색 범위·트랜잭션 경계에 따라 분석한다 |
| 인증·드라이버 | 8.4의 인증 설정을 8.0 관행으로 추측하지 않는다 |
| 관리형·호환 제품 | Aurora·Percona·MariaDB를 동일 제품으로 간주하지 않는다 |

이 표는 전체 매뉴얼의 대체물이 아니다. [공식 근거 목록](sources.md)에서 해당 기능을 확인하고 네트워크 접근이 없으면 관련 결론을 미확인 또는 조건부로 남긴다.
