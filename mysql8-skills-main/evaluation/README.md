# DA 평가 실행 안내

## 1. 기본 연습

각 스킬의 references/example.md는 DB 접속 없이 실행할 가상 입력이다. 설치 후 명시 호출하고 응답·사용 경로·CLI·모델·프로필·시간을 저장한다. 단일 스킬의 사례만 제공하고 평가 기준 문서는 에이전트 입력에서 제외한다.

## 2. 독립 평가

가능하면 DA 평가자와 실행자를 분리한다. 평가자용 [판정 기준](reviewer-rubric.md)은 기대 결과가 포함되어 있으므로 실행 에이전트가 읽지 않는 별도 경로에서 관리한다. 새 세션으로 시작한다. 예제와 기대 답을 함께 보여준 결과를 독립 평가로 집계하지 않는다.

## 3. 실제 사례

각 스킬별로 정상 사례, 결함 사례, 정보 부족 사례, 팀 예외 사례를 확보한다. MySQL 8.0과 8.4를 구분한다. 학습용 규칙·예제와 평가용 사례를 나누고 평가용 정답을 검색 문서에 넣지 않는다.

## 4. 판정

각 사례는 기대 행동별 충족/부분 충족/실패/N/A로 판정하고 근거 문장을 남긴다. 잘못된 DB 실행·허위 실행 결과·중요 문제 누락은 별도 기록한다. 정답 문구 일치가 아니라 동작과 기술 근거를 본다. 전체 결과가 좋더라도 개별 중요한 실패는 숨기지 않는다.

## 5. 회귀 평가

스킬 수정 전후 같은 입력·프로필·가능한 한 같은 모델 조건을 사용한다. 모델 출력 변동이 크거나 경계 사례라면 반복 평가한다. 대화에 정답이 노출된 상태로 재시도해 얻은 답은 별도 표기한다.

이 묶음의 생성 시 검증 범위는 [검증 기록](../docs/validation.md)에 적는다. 제공된 평가 절차와 실제 실행 완료를 혼동하지 않는다.
