# DB 실행·운영 프로필

상태: 미작성. 이 문서는 정책과 절차의 기록이며 현재 작업의 실행 승인서가 아니다. 자격 증명 값은 적지 않는다.

| 환경 | 접속 식별자·설정 위치 | 허용 작업 | 인증 수단 참조 | 실행 담당·절차 |
|---|---|---|---|---|
| 로컬 | 미정 | 미정 | 미정 | 미정 |
| 격리 테스트 | 미정 | 미정 | 미정 | 미정 |
| 공용 개발·검증 | 미정 | 미정 | 미정 | 미정 |
| 운영 | 미정 | 미정 | 미정 | 미정 |

- 로컬 실행 형태: Windows 서비스 / 컨테이너 / 원격 중 미정
- Windows 서비스 이름 또는 컨테이너 식별자: 미정
- 서비스 시작 권한과 방법: 미정
- 허용 DB·스키마와 생성 가능한 테스트 자원 범위: 미정

- SQL 실행 결과·로그 저장 및 마스킹 정책: 미정

작성 예: 이 묶음 제작 의뢰자의 PC는 Windows 서비스 MySQL84를 사용한다. 해당 PC에서 실제 MySQL 작업을 할 때 먼저 상태를 확인하고 중지되어 있으면 시작한다. 이 값을 다른 팀의 서비스 이름으로 복사하지 않는다.
