# 프로젝트 AGENTS.md 병합용 조각

아래 코드 블록의 내용만 실제 프로젝트 AGENTS.md에 필요한 범위로 병합한다. 기존 지침을 교체하지 않는다. 경로는 AGENTS.md가 프로젝트 루트에 있는 경우의 예다.

```markdown
## MySQL DB 작업

- DB_TEAM_PROFILE: docs/db/team-profile.md
- MySQL DB 작업에서는 위 프로필과 관련 팀 규칙을 읽는다. 상대 경로는 이 AGENTS.md 기준이다.
- 프로필의 미정 값은 실제 설정으로 취급하지 않는다. 가능한 정적 분석을 진행하고 부족한 정보로 제한되는 판단을 명시한다.
- DB 리뷰는 관련 mysql8-* 스킬을 선택한다. 스킬이 설치되어 있지 않으면 그 사실을 밝히고 일반 검토를 진행한다.
- 결과에서 정적 확인, 실험 확인, 미확인을 구분한다. 스킬 검토 결과는 DA 승인이나 운영 변경 승인 자체가 아니다.
```

여러 서비스가 있는 저장소는 서비스별 프로필을 선언하거나 호출 시 정확한 프로필을 지정한다. Codex가 아직 읽지 않은 하위 디렉터리의 AGENTS.md를 이미 적용한 것으로 가정하지 않는다.
