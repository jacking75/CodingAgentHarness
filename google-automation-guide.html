    2용어 사전

    이 문서의 낯선 말은 모두 여기에 있습니다. 모를 때 돌아와서 보세요. 문서 안에서는 쉬운 말을 먼저 쓰고, 괄호에 원래 용어를 적습니다.

    장소 — “어디에 있는 것인가”

    PCPC 작업 폴더
    내 컴퓨터(탐색기에서 보이는) 안의 폴더. 예: C:\automation\my-first. 에이전트가 이 안에서 자동화 파일을 만듭니다.
    드라이브드라이브 폴더
    구글 드라이브(웹, drive.google.com) 안의 폴더. 자동화가 파일을 만들고 정리하는 대상입니다. 연습할 때는 테스트용 드라이브 폴더를 씁니다.
    구글구글 서버
    구글의 컴퓨터. 올라온 자동화가 여기서 실행됩니다. 내 컴퓨터가 꺼져 있어도 됩니다.
    구글편집기
    구글 화면에서 자동화를 보고 ▶ 실행하는 곳(Apps Script 편집기). 처음 실행과 허용은 여기서 합니다.

    도구 — “무엇으로 하는가”

    코딩 에이전트
    한국어로 부탁하면 코드를 쓰고 파일을 고쳐 주는 AI 도우미 프로그램. (예: Claude Code, Codex CLI) 이 문서에서는 줄여서 에이전트라고 부릅니다.
    clasp
    내 컴퓨터의 자동화 파일을 구글로 올리고(push) 내려받는(pull) 도구. 보통 에이전트가 대신 사용합니다.
    터미널 (PowerShell)
    글자로 명령을 입력하는 창. 시작 메뉴에서 “PowerShell”을 검색해 엽니다. 명령을 입력하고 Enter를 누르면 실행됩니다.
    Node.js
    clasp가 돌아가는 데 필요한 기본 프로그램. 한 번만 설치하면 됩니다.

    자동화 — “무엇을 만드는가”

    자동화 (스크립트)
    컴퓨터가 대신 해 주는 일을 적어 둔 짧은 프로그램. 이 문서에서는 에이전트가 만듭니다.
    함수
    자동화 안의 “작업 하나”의 이름. 구글 편집기에서 이 이름을 골라 ▶ 실행합니다. 어떤 이름을 실행할지는 에이전트가 알려 줍니다.
    자동 실행 설정 (트리거)
    “매일 아침 9시에 실행”처럼 알람 시계를 맞춰 두는 것. 13장에서 설명합니다.
    권한 허용 (승인)
    처음 실행할 때 “이 자동화가 내 드라이브·메일·캘린더를 써도 되나요?” 묻는 확인 창. 내가 직접 허용해야 합니다.
    미리보기 모드 (DRY_RUN)
    실제로는 아무것도 바꾸지 않고 “이런 일을 할 예정입니다”만 보여 주는 안전 모드. 삭제·이동·발송 자동화는 항상 미리보기부터 합니다.
    실행 결과 기록 (로그)
    자동화가 실행되며 남기는 메모. 구글 편집기 아래쪽에 보이며, 결과나 오류가 여기에 나옵니다.
    요청문 (프롬프트)
    에이전트에게 하는 부탁의 말. 이 문서의 예제마다 복사해서 쓸 수 있는 요청문이 있습니다.
    규칙 파일 (CLAUDE.md / AGENTS.md)
    에이전트가 시작할 때 읽는 지침서. 안전 규칙을 한 번 적어 두면 매번 말하지 않아도 됩니다. 5장
    주소 (URL)
    브라우저 맨 위 줄에 보이는 인터넷 주소. 드라이브 폴더·파일은 이 주소를 에이전트에게 그대로 알려 주면 됩니다.

    3준비하기

    시작 전 체크리스트

    💡
    PC 작업 폴더 이름을 정할 때영문·숫자로 된 짧은 경로가 좋습니다(예: C:\automation\my-first). 한 폴더에는 한 가지 주제의 자동화만 두세요(예: “주간 보고 자동화”). 주제가 다르면 폴더를 나눕니다.

    ② clasp내 컴퓨터의 자동화 파일을 구글로 올려 주는 도구(택배 기사)에이전트가 대신 사용

    먼저, 터미널(PowerShell) 여는 법

    이 장의 명령은 모두 PowerShell이라는 “글자로 명령하는 창”에 입력합니다. Windows 키를 누르고 PowerShell을 검색해 엽니다. 파란(또는 검은) 창이 뜨면 됩니다. 아래 예시처럼 굵은 줄(명령)만 입력하고 Enter를 누르세요. PC 표시가 붙은 단계는 모두 내 컴퓨터에서 하는 일입니다.

    1. PCNode.js 설치하기 (버전 20 이상)

      nodejs.org의 LTS 버전을 내려받아 설치하거나 회사 소프트웨어 설치 센터를 이용합니다. 설치 후 PowerShell을 새로 열고 확인합니다.

      PowerShell
      PS C:\Users\me> node -v
v22.22.0          ← v20 이상이면 OK (숫자는 달라도 됩니다)
    2. PCclasp 설치하기

      한 번만 하면 됩니다. (clasp는 이후 에이전트가 대신 사용합니다.)

      PowerShell
      PS C:\Users\me> npm install -g @google/clasp
PS C:\Users\me> clasp --version
3.4.1           ← 2026년 10월 기준 최신 (3.x 이상이면 이 문서와 같습니다)

      설치 권한 오류가 나면 PowerShell을 관리자 권한으로 열어 다시 하거나, IT 담당자에게 문의하세요. PowerShell이 “스크립트를 실행할 수 없으므로…”라고 막으면 명령 프롬프트(cmd)에서 같은 명령을 입력해도 됩니다.

    3. PC코딩 에이전트 설치하기 (둘 중 하나)

      회사에서 허용한 쪽을 하나만 설치하면 됩니다. 설치한 뒤 PowerShell을 닫았다가 새로 여세요. (처음 실행할 때의 로그인은 5장에서 합니다.)

      Claude Code

      PowerShell
      PS C:\Users\me> irm https://claude.ai/install.ps1 | iex
PS C:\Users\me> claude --version
버전 숫자가 나오면 OK

      규칙 파일 이름: CLAUDE.md

      Codex CLI

      PowerShell
      PS C:\Users\me> npm install -g @openai/codex
PS C:\Users\me> codex --version
버전 숫자가 나오면 OK

      규칙 파일 이름: AGENTS.md

      설치 방법은 업데이트될 수 있습니다. 안 될 때는 각 공식 안내(문서 맨 아래 “참고한 공식 자료”)를 확인하세요. 이 문서의 예제는 두 에이전트 모두 똑같이 사용할 수 있습니다.

    4. 구글구글에서 “Google Apps Script API” 켜기

      브라우저로 script.google.com/home/usersettings 를 열고 Google Apps Script API를 사용으로 바꿉니다. 꺼져 있으면 clasp가 “User has not enabled the Apps Script API” 오류를 냅니다.

    5. PCclasp 로그인 (처음 한 번)

      PowerShell에 아래를 입력하면 브라우저 창이 열립니다. 회사 계정을 고르고 허용하면 끝입니다.

      PowerShell
      PS C:\Users\me> clasp login
(브라우저가 열립니다 → 회사 계정 선택 → 허용)
로그인 성공 안내가 표시되면 PowerShell로 돌아옵니다

      브라우저가 자동으로 안 열리면 clasp login --no-localhost 로 하고, 안내되는 주소를 직접 열어 나온 코드를 붙여넣습니다.

      🔑
      로그인 정보 파일은 비밀번호와 같습니다로그인하면 내 사용자 폴더에 .clasprc.json 파일이 생깁니다. 이 파일이 있으면 내 Apps Script 프로젝트에 접근할 수 있으니 메신저·메일·Git에 올리거나 남에게 보내지 마세요. 에이전트에게도 열어 보라고 하지 마세요(규칙 파일에 금지로 적어 둡니다).
    🚧
    로그인이 막히면회사 구글 관리자가 “외부 앱 접근”을 제한한 경우 clasp login 중에 “앱이 차단됨” 또는 “관리자가 접근을 제한했습니다” 비슷한 화면이 나올 수 있습니다. 이때는 IT 담당자에게 “Google Apps Script CLI(clasp)와 Apps Script API 사용 허용”을 요청하세요. 허용되기 전에는 부록 A의 방법으로 먼저 시작할 수 있습니다.
    개발자 메모 (비전공자는 건너뛰어도 됩니다)
    • clasp run-function(내 PC에서 함수 바로 실행)은 직접 만든 OAuth 클라이언트와 Google Cloud 프로젝트가 필요해 이 문서에서는 쓰지 않습니다. 그래서 실행은 구글 편집기의 ▶ 실행과 트리거로 합니다. clasp login 자체는 별도 OAuth 설정이 필요 없습니다.
    • clasp 3.x는 명령 이름이 길어졌습니다(create-script, clone-script, open-script). 2.x 이름(create, clone)은 별칭으로 남아 있습니다.
    • clasp push는 코드 파일(.js/.gs/.html)과 appsscript.json을 올립니다. 올리고 싶지 않은 파일은 .claspignore로 제외합니다.

    5작업 폴더 만들고 에이전트 시작하기

    자동화 하나(또는 한 주제)마다 PCPC 작업 폴더를 하나 만들고, 그 안에 규칙 파일을 두고, 그 폴더에서 에이전트를 시작합니다. 규칙 파일 덕분에 안전 규칙을 매번 말하지 않아도 됩니다.

    🧭
    이 장의 폴더는 모두 PC 작업 폴더입니다구글 드라이브의 폴더(드라이브)가 아닙니다. 둘의 차이는 3장의 그림 2를 보세요.
    1. PCPC 작업 폴더 만들기

## 코드 규칙
- 언어는 Google Apps Script(V8)만 쓴다. 외부 인터넷으로 데이터를 보내는 코드(UrlFetchApp 등)와 외부 라이브러리는 쓰지 않는다.
- 요청에 필요한 서비스만 쓴다 (DriveApp, CalendarApp, MailApp, GmailApp, SpreadsheetApp).
- 삭제·이동·이름 변경·공유 변경·일정 삭제·메일 발송 같은 되돌리기 어려운 동작은 DRY_RUN = true를 기본값으로 둔다. DRY_RUN일 때는 "무엇을 할 예정인지"만 Logger.log로 보여 준다.
- 삭제가 필요하면 휴지통 이동만 쓴다. 영구 삭제는 하지 않는다.
- 메일은 별도 요청이 없으면 나에게만 보낸다.
- 바꿀 값(폴더 ID, 메일 주소, 기간 등)은 코드 맨 위 상수로 모으고 쉬운 한국어 주석을 단다.
- 같은 메일·파일·일정을 두 번 처리하지 않도록 처리 완료 표시(라벨, 시트 칸 등)를 넣는다.
- 시간대는 Asia/Seoul이다. appsscript.json의 timeZone도 Asia/Seoul로 맞춘다.
- 한 번 실행은 6분을 넘기면 안 되므로, 대상이 많으면 나누어 처리한다.
- 결과와 진행 상황은 Logger.log로 남긴다.

## 작업 순서
- 작업을 시작할 때 먼저 clasp pull로 구글의 최신 내용을 받는다 (브라우저에서 고쳤을 수 있다).
- 코드를 쓰거나 고치면 clasp push로 구글에 올린다.
- 올린 뒤 사람에게 알린다: (1) 구글 편집기에서 어떤 함수를 ▶ 실행할지 (2) 권한 허용 창이 뜰 수 있는지 (3) 실행 로그에서 무엇을 확인할지.
- clasp run, clasp run-function은 쓰지 않는다 (우리 환경에서는 쓸 수 없다). 실행은 사람이 구글 화면에서 한다.

    function addDatePrefix() {
  const DRY_RUN = true;   // true = 미리보기(로그만) / false = 진짜로 이름 바꾸기
  const today = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyyMMdd');
  const folder = DriveApp.getFolderById('여기에_폴더ID');

  const files = folder.getFiles();
  while (files.hasNext()) {
    const file = files.next();
    const oldName = file.getName();
    if (oldName.startsWith(today)) continue;      // 이미 붙어 있으면 건너뜀
    const newName = today + '_' + oldName;
    Logger.log(oldName + '  →  ' + newName);
    if (!DRY_RUN) file.setName(newName);
  }
}

    function movePdfFiles() {
  const DRY_RUN = true;   // true = 미리보기(로그만) / false = 진짜로 옮기기
  const from = DriveApp.getFolderById('여기에_원본폴더ID');
  const to = DriveApp.getFolderById('여기에_PDF폴더ID');
  const files = from.getFilesByType(MimeType.PDF);   // PDF만 골라옴
  let count = 0;
  while (files.hasNext()) {
    const file = files.next();
    Logger.log((DRY_RUN ? '[미리보기] ' : '[이동] ') + file.getName());
    if (!DRY_RUN) file.moveTo(to);

// 이름 끝의 _ 는 “도우미 함수” 표시입니다 (실행 목록에는 나타나지 않습니다)
function countFolder_(folder, result) {
  const files = folder.getFiles();
  while (files.hasNext()) {
    const f = files.next();
    result.files++;
    result.bytes += f.getSize();
  }
  const subs = folder.getFolders();
  while (subs.hasNext()) {
    countFolder_(subs.next(), result);   // 하위 폴더도 같은 방법으로 세기
  }
}

  const TZ = 'Asia/Seoul';
  const DAYS = ['일', '월', '화', '수', '목', '금', '토'];
  const now = new Date();
  const diffToMonday = (now.getDay() + 6) % 7;   // 오늘이 월요일이면 0, 화요일이면 1 …
  const start = new Date(now.getFullYear(), now.getMonth(), now.getDate() - diffToMonday);
  const end = new Date(start.getFullYear(), start.getMonth(), start.getDate() + 7);

  const events = CalendarApp.getDefaultCalendar().getEvents(start, end);

  events.forEach(e => {

    rows.push([

      DAYS[s.getDay()],
      e.isAllDayEvent() ? '종일' : Utilities.formatDate(s, TZ, 'HH:mm') + '~' + Utilities.formatDate(e.getEndTime(), TZ, 'HH:mm'),
      e.getTitle(),
      e.getLocation()
    ]);
  });

  const ss = SpreadsheetApp.create('주간 일정 ' + Utilities.formatDate(start, TZ, 'MMdd'));
  ss.getActiveSheet().getRange(1, 1, rows.length, rows[0].length).setValues(rows);

    function meetingHoursThisMonth() {
  const now = new Date();
  const start = new Date(now.getFullYear(), now.getMonth(), 1);       // 이번 달 1일
  const end = new Date(now.getFullYear(), now.getMonth() + 1, 1);     // 다음 달 1일

  const events = CalendarApp.getDefaultCalendar().getEvents(start, end);
  let minutes = 0;
  let count = 0;
  events.forEach(e => {
    if (e.isAllDayEvent()) return;                 // 종일 일정은 제외
    if (e.getGuestList().length === 0) return;    // 참석자가 없는 개인 일정은 제외
    minutes += (e.getEndTime() - e.getStartTime()) / 60000;
    count++;
  });
  Logger.log('이번 달 회의 ' + count + '건, 합계 ' + (minutes / 60).toFixed(1) + '시간');
}

    function sheetToCalendar() {
  const DRY_RUN = true;   // true = 미리보기(로그만) / false = 진짜로 등록
  const sheet = SpreadsheetApp.openById('여기에_스프레드시트ID').getSheets()[0];
  const cal = CalendarApp.getDefaultCalendar();
  const rows = sheet.getDataRange().getValues();      // 표 전체를 읽어옴

  for (let i = 1; i < rows.length; i++) {              // i = 1 → 2번째 줄부터 (1줄은 제목줄)
    const title = rows[i][0];
    const start = rows[i][1];
    const end = rows[i][2];
    const guests = rows[i][3];
    const status = rows[i][4];
    if (!title || status === '등록완료') continue;    // 빈 줄·이미 등록한 줄은 건너뜀

    Logger.log((DRY_RUN ? '[미리보기] ' : '[등록] ') + title + ' / ' + start + ' ~ ' + end);
    if (DRY_RUN) continue;
    const options = guests ? { guests: String(guests), sendInvites: true } : {};
    cal.createEvent(title, new Date(start), new Date(end), options);
    sheet.getRange(i + 1, 5).setValue('등록완료');      // 같은 줄이 두 번 등록되지 않게 표시
  }
  Logger.log('등록 완료');
}

  const DONE = '저장완료';                                        // 처리한 메일에 붙일 라벨

          saved++;
        }
      });
    });
    thread.addLabel(doneLabel);                                    // “처리했음” 표시
  });
  Logger.log('PDF ' + saved + '개를 저장했습니다.');
}

    function autoReply() {
  const DRY_RUN = true;   // true = 미리보기(로그만) / false = 진짜로 답장
  const DONE = '자동답장완료';
  const label = GmailApp.getUserLabelByName(DONE) || GmailApp.createLabel(DONE);

  const threads = GmailApp.search('in:inbox is:unread subject:문의 -label:' + DONE, 0, 20);
  threads.forEach(thread => {
    Logger.log((DRY_RUN ? '[미리보기] ' : '[답장] ') + thread.getFirstMessageSubject());
    if (DRY_RUN) return;
    thread.reply('문의 주셔서 감사합니다. 접수되었으며 영업일 기준 1~2일 안에 답변드리겠습니다.');
    thread.addLabel(label);                     // 같은 메일에 또 답장하지 않게 표시
  });
  Logger.log((DRY_RUN ? '[미리보기 끝] 대상 ' : '답장 완료 ') + threads.length + '건');
}

    ⚠ 자동 답장은 외부 사람에게도 나갑니다. 회사 정책을 확인하고, 메일링 리스트나 자동 발송 메일(no-reply)에는 답장하지 않도록 조건을 좁게 잡으세요. 미리보기로 어떤 메일이 잡히는지 먼저 확인한 뒤 “이제 진짜로 답장하게 바꿔서 clasp push 해줘”라고 말하세요.

    13자동으로 실행하기 (트리거)

    “매일 아침 9시”, “1시간마다”처럼 내가 버튼을 누르지 않아도 실행되게 하는 알람 시계입니다. 자동 실행 설정(트리거)은 구글 서버에서 돌기 때문에 내 컴퓨터를 꺼 두어도 됩니다.

    1자동화 만들기에이전트에게 부탁하고 올리기
    →
    2한 번 직접 실행잘 되는지, 권한 허용까지 끝내기
    →
    3자동 실행 설정언제 실행할지 시계 맞추기
    →
    4며칠 지켜보기실행 기록·실패 알림 확인

    방법 1 · 구글 화면에서 설정하기 (눈으로 확인할 수 있어 가장 쉬움)

    구글구글 편집기(clasp open-script로 엽니다)에서 합니다.

    방법 2 · 에이전트에게 부탁하기 (여러 개를 한 번에 만들 때)

    자동 실행 설정도 에이전트가 대신 만들어 줍니다. 설정을 만드는 자동화를 딱 한 번만 구글 편집기에서 ▶ 실행하면 됩니다. 두 번 실행해도 중복되지 않도록 “같은 설정을 먼저 지우고 다시 만드는” 방식으로 부탁하세요.

    💬 에이전트에게 이렇게 부탁하세요
    'morningBriefing' 자동화를 매일 오전 9시대에 자동으로 실행되게 하는 설정을 만들어줘. 같은 설정이 중복으로 생기지 않게, 이미 있으면 먼저 지우고 다시 만들게 해줘. 다 만들면 clasp push까지 하고, 구글 편집기에서 내가 할 일을 알려줘.

    몇 분마다“15분마다 실행”1·5·10·15·30분 중에서만 가능
    몇 시간마다“1시간마다 / 2시간마다 실행”
    매일“매일 오전 9시대에 실행”9~10시 사이 어느 때

    이 프로젝트에 설정된 자동 실행(트리거)을 모두 지우는 자동화를 만들어줘. 지우기 전에 어떤 설정들이 있는지 목록을 로그에 보여줘. 다 만들면 clasp push까지 하고, 구글 편집기에서 내가 할 일을 알려줘.

    function installDailyTrigger() {
  // 이미 있는 같은 트리거는 지우고(중복 방지)
  ScriptApp.getProjectTriggers().forEach(t => {
    if (t.getHandlerFunction() === 'morningBriefing') ScriptApp.deleteTrigger(t);

    자동 실행을 쓸 때 꼭 알아 둘 것

    ① 정확한 시각이 아닙니다. “9시”는 9시~10시 사이 어느 때든 실행됩니다.

    ② 자동 실행은 만든 사람의 권한과 계정으로 실행됩니다. 그 사람의 계정이 정지·삭제되면 멈춥니다. 중요한 자동화는 담당자를 정해 두고 인수인계하세요.

    ③ 설정하기 전에 그 함수를 편집기에서 직접 한 번 ▶ 실행해 권한 허용을 끝내 두세요. 허용이 안 된 채로는 자동 실행이 실패합니다.

    ④ 한 번 실행은 최대 6분, 한 프로젝트당 설정은 최대 20개입니다.

    ⑤ 실행 결과는 구글 편집기 왼쪽 메뉴 실행에서 시각별로 볼 수 있고, 실패하면 “실패 알림” 메일이 옵니다.

    ⑥ 코드를 고치면(에이전트가 다시 올리면) 이미 맞춰 둔 자동 실행에도 바로 새 코드가 적용됩니다. 의도하지 않은 변경이 없는지 올린 뒤 한 번 직접 실행해 보세요.

    E-1보내기

    매일 아침 “오늘 일정 + 안 읽은 메일 수” 요약 메일 받기

    이럴 때: 출근하자마자 오늘 할 일을 한 통의 메일로 보고 싶을 때. 메일은 항상 나에게만 갑니다.

    💬 에이전트에게 이렇게 부탁하세요
    매일 아침 나에게 '오늘 일정 + 안 읽은 메일 수'를 요약한 메일을 보내는 자동화를 만들어줘. 제목: [아침 브리핑] 10월 12일 (오늘 날짜) 본문: '좋은 아침입니다!' 인사 → '[오늘 일정 N건]' 아래에 시간과 제목 목록(종일 일정은 '종일', 없으면 '일정 없음') → '[안 읽은 메일] N통' 받는 사람은 항상 나뿐이야. 매일 아침 8~9시에 자동으로 실행되게 하는 방법도 쉽게 알려줘. 다 만들면 clasp push까지 하고, 구글 편집기에서 내가 할 일(실행할 함수, 허용 창, 확인할 로그)을 알려줘.
    🧩 에이전트가 만드는 코드의 예 (읽지 않아도 됩니다)
    function morningBriefing() {
  const TZ = 'Asia/Seoul';
  const me = Session.getEffectiveUser().getEmail();
  const today = Utilities.formatDate(new Date(), TZ, 'M월 d일');

  // 1) 오늘 일정 모으기
  const events = CalendarApp.getDefaultCalendar().getEventsForDay(new Date());
  const lines = events.map(e => {
    const when = e.isAllDayEvent() ? '종일' : Utilities.formatDate(e.getStartTime(), TZ, 'HH:mm');
    return '• ' + when + '  ' + e.getTitle();
  });

  // 2) 받은편지함에서 안 읽은 메일 수
  const unread = GmailApp.getInboxUnreadCount();

  // 3) 한 통으로 정리해서 나에게 보내기
  const body = '좋은 아침입니다!\n\n'
    + '[오늘 일정 ' + events.length + '건]\n'
    + (lines.length ? lines.join('\n') : '• 일정 없음')
    + '\n\n[안 읽은 메일] ' + unread + '통';
  MailApp.sendEmail(me, '[아침 브리핑] ' + today, body);
}

    E-2보내기

    공유 폴더에 새 파일이 올라오면 알림 메일 받기

    이럴 때: 팀 공유 폴더에 누가 자료를 올렸는지 바로 알고 싶을 때. 새 파일이 없으면 메일을 보내지 않습니다.

    💬 에이전트에게 이렇게 부탁하세요
    이 공유 폴더에 최근 1시간 안에 새로 생긴 파일이 있으면, 파일 이름과 주소를 모아 나에게 알림 메일을 보내는 자동화를 만들어줘. 새 파일이 없으면 메일을 보내지 마. 감시할 폴더: 드라이브 폴더 주소 제목: [새 파일 N개] 자료 폴더 알림 받는 사람은 나뿐이야. 이 자동화는 1시간마다 실행할 거야. 다 만들면 clasp push까지 하고, 구글 편집기에서 내가 할 일(실행할 함수, 허용 창, 확인할 로그)을 알려줘.

    function notifyNewFiles() {
  const folder = DriveApp.getFolderById('여기에_감시폴더ID');
  const since = new Date(Date.now() - 60 * 60 * 1000);   // 지금부터 1시간 전

  const lines = [];
  const files = folder.getFiles();
  while (files.hasNext()) {
    const f = files.next();
    if (f.getDateCreated() > since) {                    // 최근 1시간 안에 생긴 파일만
      lines.push('• ' + f.getName() + '\n  ' + f.getUrl());
    }
  }
  if (lines.length === 0) return;                         // 새 파일이 없으면 끝

  const me = Session.getEffectiveUser().getEmail();
  MailApp.sendEmail(me, '[새 파일 ' + lines.length + '개] 자료 폴더 알림', lines.join('\n'));
}

    function weeklyReportDraft() {
  const TZ = 'Asia/Seoul';
  const now = new Date();
  // 금요일에 실행한다고 가정: 월요일 0시부터 오늘 끝까지의 일정
  const start = new Date(now.getFullYear(), now.getMonth(), now.getDate() - 4);

  const events = CalendarApp.getDefaultCalendar().getEvents(start, end)
    .filter(e => !e.isAllDayEvent());
  const lines = events.map(e => '- ' + Utilities.formatDate(e.getStartTime(), TZ, 'MM/dd') + '  ' + e.getTitle());

  const body = '안녕하세요.\n\n이번 주 업무 내용을 공유드립니다.\n\n'
    + '[이번 주 일정]\n' + (lines.length ? lines.join('\n') : '- (없음)') + '\n\n'
    + '[진행 내용]\n1. \n2. \n\n'
    + '[다음 주 계획]\n1. \n\n'
    + '감사합니다.';

  GmailApp.createDraft('여기에_팀장메일', '[주간보고] ' + Utilities.formatDate(now, TZ, 'M/d') + ' 주차', body);
  Logger.log('초안을 만들었습니다.');
}

    에이전트가 만든 함수가 구글 편집기 목록에 안 보여요

    ① 에이전트가 clasp push까지 했는지 확인합니다(“올렸습니다”라는 말이 없으면 “clasp push 해줘”라고 부탁). ② 구글 편집기 탭을 새로고침합니다. ③ PC의 연결 정보가 내가 보는 프로젝트가 맞는지 clasp open-script 로 열어 확인합니다.

    User has not enabled the Apps Script API

    구글 편집기에서 직접 고친 뒤 에이전트가 clasp push를 하면 PC 쪽 내용으로 덮어써집니다. 앞으로는 고칠 일이 있으면 에이전트에게 부탁하세요. 이미 사라졌다면 편집기 왼쪽 프로젝트 기록에서 이전 버전을 볼 수 있는 경우가 있습니다.

    “승인 필요” 창이 계속 나와요

    Exception: You do not have permission to call DriveApp…

    해당 서비스 권한이 아직 허용되지 않았습니다. 편집기에서 함수를 직접 한 번 ▶ 실행해 허용을 마치세요. 허용 창이 안 나오면 에이전트에게 오류 문구를 붙여넣고 “권한 문제를 고쳐줘”라고 하세요.

    Exception: Unexpected error while getting the method or property getFolderById…

    폴더·파일 주소(ID)가 틀렸거나, 내 계정이 그 폴더를 볼 수 없는 경우입니다. 브라우저 주소창에서 주소를 다시 복사해 요청문에 넣고(8장), 같은 계정으로 그 폴더가 열리는지 확인하세요.

    SyntaxError / ReferenceError / TypeError 같은 빨간 오류

    자동화 안의 오류입니다. 구글 편집기의 실행 로그 빨간 글씨를 통째로 복사해서 에이전트에게 붙여넣고 “이 오류를 고치고 clasp push까지 해줘”라고 하세요. 대부분 한 번에 해결됩니다.

    Service invoked too many times for one day: email

    하루 메일 발송 한도를 넘었습니다. 내일(약 24시간 뒤) 다시 가능하며, 그 전에는 발송 대상을 줄이거나 나누어야 합니다. 15장의 사용 한도를 참고하세요.

    6분 안에 끝나지 않았습니다. 에이전트에게 “한 번에 처리하는 양을 줄이고, 여러 번에 나누어 실행되게 바꿔줘”라고 하세요.

    자동 실행(트리거)이 안 돌아요

    이 문서의 중심은 코딩 에이전트를 쓰는 방법입니다. 아래는 “이런 방법도 있다” 정도의 참고입니다. 설치가 막혀 있거나, 아주 간단한 시험만 해 볼 때 씁니다.

    순서 (설치 없이 10분)

    1. 구글Apps Script 사이트 열기

      브라우저 주소창에 script.google.com 을 입력합니다. 오른쪽 위 프로필이 회사 계정인지 확인하고 새 프로젝트 버튼을 누릅니다.

    2. 프로젝트 이름 정하기

      왼쪽 위 “제목 없는 프로젝트”를 눌러 내 첫 자동화 처럼 알아보기 쉬운 이름으로 바꿉니다.

    3. 코드 붙여넣기

      이 문서 예제의 “에이전트가 만드는 코드의 예”를 펼쳐 복사 버튼으로 복사합니다. 구글 편집기 가운데 코드 영역(Code.gs)의 내용을 Ctrl+A → Delete 로 지우고 붙여넣은 뒤 Ctrl+S로 저장합니다.

      • 코드 안의 노란색으로 표시된 부분(예: 여기에_폴더ID)은 내 값으로 바꿔 넣는 자리입니다. 따옴표(')는 그대로 두세요. ID는 8장.
      • 한 파일에 같은 이름의 함수가 두 개 있으면 오류가 납니다. 예제를 여러 개 쓸 때는 ＋ → 스크립트로 새 파일을 만들어 하나씩 붙이세요.
    4. 함수 고르고 ▶ 실행, 권한 허용, 로그 확인

      이후는 6장의 5~7단계와 똑같습니다.
