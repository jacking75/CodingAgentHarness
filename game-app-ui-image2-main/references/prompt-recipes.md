# Prompt recipes

Use these as starting scaffolds. Retain only details that materially help the request.

## PC/console game HUD

```text
Use case: ui-mockup
Asset type: gameplay HUD design reference
Primary request: <genre> gameplay HUD for <core player goal>
Platform and viewport: 16:9, 2560x1440
Information hierarchy: center gameplay unobstructed; player status first; objective and contextual actions second
States shown: normal gameplay with one selected ability
Style/medium: <art direction>
Composition: reserve the center 60% for gameplay; use corner-safe placement; align information on a clear grid
Text (verbatim): "<only essential labels>"
Constraints: original UI, no device frame, no watermark, readable at play distance
Avoid: obscuring enemies or navigation, dense microcopy, copied game-brand UI
```

## Mobile app task screen

```text
Use case: ui-mockup
Asset type: mobile app screen design reference
Primary request: <screen name> that enables the user to <primary task>
Platform and viewport: portrait mobile, 9:16
Information hierarchy: primary action first; supporting context second; navigation tertiary
States shown: populated normal state
Style/medium: <brand mood and material language>
Color palette: <roles for surface, action, feedback, and text>
Composition: thumb-reachable primary action; platform-safe top and bottom areas; generous touch targets
Text (verbatim): "<only essential copy>"
Constraints: original UI, no device frame, no watermark, clear visual grouping
Avoid: fake tiny paragraphs, inaccessible low contrast, unnecessary charts
```

## Illustrated menu panel or image asset

```text
Use case: ui-mockup
Asset type: game menu background or illustrated UI panel
Primary request: <asset and its function>
Platform and viewport: <aspect ratio>
Style/medium: <art direction>
Composition: preserve empty space for native UI overlays at <placement>
Color palette: <palette>
Constraints: no text unless explicitly required; no watermark; clean edges; original design
Avoid: decorative elements inside the reserved UI space
```
